### Quick Start

<div align="center">

```bash
# Clone
git clone https://github.com/nawala-team/rachana-code.git && cd rachana-code

# Install
npm install

# Run
npm run electron:dev
```

</div>

### Keyboard Shortcuts

<div align="center">

| Shortcut | Action |
|:--------:|:------:|
| `Ctrl+Shift+P` | Command Palette |
| `Ctrl+Shift+F` | Search in Files |
| `Ctrl+S` | Save |
| `Ctrl+N` | New File |
| `Ctrl+B` | Toggle Sidebar |
| `Ctrl+J` | Toggle Terminal |
